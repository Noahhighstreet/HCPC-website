HCPC Website – Technische Toelichting
Structuur van de website

De website is opgebouwd uit meerdere HTML-pagina's die via een navigatiebalk met elkaar verbonden zijn:

- HCPC.html (Home)
- missie.html
- product.html
- overons.html
- contact.html

Alle pagina's maken gebruik van hetzelfde CSS-bestand (HCPC.css) zodat de volledige website een uniforme uitstraling heeft.


Gebruikte technologieën

Voor deze website werden volgende technologieën gebruikt:

HTML voor de structuur en inhoud
CSS voor de opmaak en vormgeving
JavaScript voor de cookie-banner


Navigatie

De navigatiebalk is aanwezig op elke pagina zodat gebruikers eenvoudig kunnen navigeren tussen de verschillende onderdelen van de website. Het HCPC-logo fungeert eveneens als knop die de gebruiker terug naar de homepagina brengt.


Responsive design

De website is mobielvriendelijk gemaakt met behulp van een media query:

@media screen and (max-width: 700px)

Hierdoor past de lay-out zich automatisch aan kleinere schermen zoals smartphones aan.


JavaScript

Er werd een eenvoudige JavaScript-functie toegevoegd voor de cookie-banner. Wanneer de gebruiker op de knop "OK" klikt, verdwijnt de banner.


Designkeuzes

Er werd gekozen voor een eenvoudige zwart-witte kleurenset omdat deze professioneel oogt en goed aansluit bij een technologiebedrijf. De vormgeving is bewust overzichtelijk gehouden zodat bezoekers snel de gewenste informatie kunnen vinden.


Footer

In de footer zijn de belangrijkste wettelijke en contactgegevens opgenomen, waaronder:

Copyright
Privacybeleid
Cookiebeleid
Algemene voorwaarden
Contactinformatie
Doel van de website


De website dient als online voorstelling van HCPC. Bezoekers kunnen informatie vinden over het bedrijf, de missie en visie, de aangeboden producten en contactgegevens. Daarnaast bevat de website verschillende call-to-actions om potentiële klanten aan te moedigen contact op te nemen.
